# 黑鸦标题风格

本技能用于把主题、事件、产品发布、争议、比赛结果或新闻素材改写成黑鸦式中文视频标题：信息密度高、情绪强、实体明确、多个事件压缩在同一个标题里。

## 引用资料

使用本技能前，必须查看并吸收以下引用资料，再开始改写标题：
1. `references/00-llm-brief.md`：LLM 优先读取的压缩摘要，包含核心风格、生成配方、高频素材和代表样本。

2. `references/02-style-analysis.md`：人类可读的完整风格分析报告，需要更细校准时再读。

3. `references/02-style-analysis.yaml`：结构化分析数据，用于程序读取聚合字段；LLM 不需要全文读取。

4. `references/01-titles.csv`：原始标题样本，用于按需查找真实标题语感、标点节奏和近期用词。

5. `references/03-title-features.json`：逐标题 tokens/entities/clauses 调试数据，体量较大。不要全文读取；只有排查具体标题的分词或实体问题时，按 bvid/title 精确检索单条记录。

如果引用资料和下方摘要有差异，以 `references/` 中的最新资料为准。不要只凭本文件里的摘要生成标题；摘要负责快速定位，引用资料负责校准细节。

## 核心特征

- NLP 引擎：hanlp 分词/POS/NER，样本 125 条。
- 标题长度：平均 54.2 字，P75 64 字，P90 72 字；84% 超过 40 字。
- 信息密度：平均 4.4 个分句，平均 4.21 个分隔符。
- 情绪强度：17.6% 以感叹号收尾，12.8% 使用疑问钩子。
- 实体钩子：98.4% 带实体；高频实体包括 AI日报、OpenAI、DeepSeek、Gemini、GPT、Claude、MiniMax、Anthropic、|、奥特曼、马斯克、腾讯。
- 主导结构：「emotion_burst」命中 91.2%，常与实体、动作、荒诞意象和行业后果组合。
<!-- AUTO_END:core-features -->

<!-- AUTO_START:core-guidance -->
写作时把标题当成荒诞新闻戏剧：情绪钩子 → 实体人格化 → 荒诞身体反应（瘫坐/癫痫/冷汗） → 核弹级后果 → 集体命运（死刑/斩杀线） → 日报收束。核心配方：地震/核弹 + 瘫坐/椅子爆炸 + 炼化/夺舍 + 集体死刑/斩杀线。

## 写作规则

**输出格式**：默认一个长标题，直接输出。用户要多个时，给 3-5 列标注 `序号. {风格}式：{标题}`。日报类保留 `| AI日报MMDD` 收束标签。风格标签：情绪爆点、多事件合并、数字悬念、日报、对比冲突。

**硬约束**：
1. 保留用户事实，不编造。不确定用"或将、疑似、被曝"。
2. 最强冲突放最前，≥4 分句用 `！；，|` 串联，越长越黑鸦味。
3. 情绪服务于事实：可戏剧化但不把不确定写成确定。
4. 避免短平标题和泛泛词（"来了""看看"），多用具体实体、数字、后果。

**黑鸦风格精髓**：
5. **荒诞身体 + 标志句式**：用不可能的动作写企业竞争——瘫坐、椅子爆炸、冷汗直流、癫痫、头皮发麻、后背发凉。标志句：`{人物} 瘫坐在{X}上，仿佛看到了{椅子爆炸}`。绝对避免"受到影响""感到压力"。
6. **仙侠 + 战争隐喻**：炼化、夺舍、祭出、龙王归来、诸神之战；核弹、核冬天、雪崩、海啸、血洗、血流成河。模型发布 = 引爆核弹，裁员 = 血流成河。
7. **人格化 + 荒谬动作**：不是"A 被批评"而是"A 全员颤抖/底裤露出"。不是"出故障"而是"开错生死簿/夺舍用户"。不是"竞争"而是"追杀/打到门口"。
8. **集体惩罚收尾**：X 已被判处死刑 / Y 的斩杀线来了 / Z 必须移交军事法庭。用 `……` 制造悬念和命运感。
9. **情绪强度对标黑鸦极强级**：每标题 ≥2 个情绪引爆词（地震、核弹、杀疯、沸腾、疯狂、炸裂）+ ≥1 个身体反应词（瘫坐、癫痫、冷汗）+ ≥1 个荒诞意象（椅子爆炸、核弹、开错生死簿、炼化）。
